
# 🚀 Space Shooter Game

A retro‑style browser shooting game built with **HTML5 Canvas** and **JavaScript**.  
Move your spaceship, blast enemies, and survive as long as you can!

---

## 🎮 Features
- Player‑controlled spaceship with smooth movement
- Shooting mechanics with cooldown
- Random enemy spawning with increasing difficulty
- Collision detection and scoring system
- Game over screen with restart option
- Flickering starfield background for a retro vibe

---

## 🕹️ Controls
- **Left Arrow / A** → Move left  
- **Right Arrow / D** → Move right  
- **Spacebar** → Shoot
